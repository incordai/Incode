# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- **Be respectful.** Disagree with ideas, not people. Assume good faith.
- **Not welcome:** harassment, insults, personal or political attacks,
  unwelcome sexual attention, publishing someone's private information, and
  bad-faith participation.
- **Where it applies:** issues, pull requests, reviews, discussions, and
  anywhere you represent the project.

## Enforcement

The maintainers may remove comments, commits or other contributions that break
this code, and may warn, restrict or ban anyone who makes the project worse for
others.

## Reporting

Report a conduct issue to the maintainers through GitHub. If it needs to stay
private, say so in your first message and it will be handled privately. Every
report is read, and the reporter's identity is kept confidential.
